# Estoque geral — Divergências de insumos

Submódulo de auditoria de estoque de insumos.

## Como acessar

1. **Estoque Hub → card Divergências** (abre direto na tela)
2. **Estoque → Matéria-Prima / Embalagens → sidebar Divergências**
3. Barra de navegação (view `estoque_divergencias`) se já estiver nessa tela

## Conteúdo

- Lista + drawer estilo Compras
- Extrato: NFs, baixas OP, acertos/ajustes classificados
- APIs: `/api/estoque/insumos/divergencias*`
- Schema: `Backend/supabase/009_insumo_stock_divergencias.sql`
- Discovery ERP: `erp-import/MOVIMENTOS-INSUMOS.md`
